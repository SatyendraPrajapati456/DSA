**Question Name:** 2124. Check if All A's Appears Before All B's

**Question Description:**

Given a string s consisting of only the characters 'a' and 'b', return true if every 'a' appears before every 'b' in the string. Otherwise, return false.

OriginalJavaExample 1:

Input: s = "aaabbb"
Output: true
Explanation:
The 'a's are at indices 0, 1, and 2, while the 'b's are at indices 3, 4, and 5.
Hence, every 'a' appears before every 'b' and we return true.

Example 2:

Input: s = "abab"
Output: false
Explanation:
There is an 'a' at index 2 and a 'b' at index 1.
Hence, not every 'a' appears before every 'b' and we return false.

Example 3:

Input: s = "bbb"
Output: true
Explanation:
There are no 'a's, hence, every 'a' appears before every 'b' and we return true.

Constraints:

• 1 <= s.length <= 100

• s[i] is either 'a' or 'b'.

## 3. AI-Generated Approach

### Approach: Single Pass Flag Tracking

The condition 'all a's appear before all b's' is violated if and only if an 'a' is encountered after at least one 'b' has already been seen.

**Step-by-Step Reasoning:**
1. Initialize a mechanism to track if the character 'b' has been encountered (e.g., a boolean flag or a Set).
2. Iterate through the string character by character from left to right.
3. If the current character is 'a' and the 'b' flag is already set to true, return false immediately.
4. If the current character is 'b', update the flag to true.
5. If the loop finishes without finding an 'a' after a 'b', return true.

**Why It Works:**
In a valid string, the sequence must follow the pattern a*b*. Any occurrence of 'a' after 'b' creates a 'ba' subsequence, which contradicts the requirement.

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean checkString(String s) {
        int n = s.length();
        Set<Character> seen = new HashSet<>();
        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            if (seen.contains('b') && c == 'a') {
                return false;
            }
            seen.add(c);
        }
        return true;
    }
}
```
