# 42. Trapping Rain Water

## 1. Problem Details

**Platform:** LeetCode

**Question Link:**
https://leetcode.com/problems/trapping-rain-water/description/

**Question Name:** 42. Trapping Rain Water

**Question Description:**

Given n non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.



 


Example 1:



Input: height = [0,1,0,2,1,0,1,3,2,1,2,1]
Output: 6
Explanation: The above elevation map (black section) is represented by array [0,1,0,2,1,0,1,3,2,1,2,1]. In this case, 6 units of rain water (blue section) are being trapped.


Example 2:



Input: height = [4,2,0,3,2,5]
Output: 9


 


Constraints:




	• n == height.length
	• 1 <= n <= 2 * 104
	• 0 <= height[i] <= 105

## 3. AI-Generated Approach

### Approach: Prefix and Suffix Maxima (Dynamic Programming)

For any bar at index i, the amount of water it can hold is determined by the minimum of the highest bar to its left and the highest bar to its right, minus its own height. By precomputing prefix and suffix maximums, we can compute the water trapped at each index in O(1) time.

**Step-by-Step Reasoning:**
1. Handle edge cases where the input array has length less than 3, as at least 3 bars are needed to trap water.
2. Initialize two arrays, `left` and `right`, each of size `n`.
3. Populate `left` such that `left[i]` stores the maximum height from index `0` up to `i`.
4. Populate `right` such that `right[i]` stores the maximum height from index `n - 1` down to `i`.
5. Iterate through the array from index `0` to `n - 1`, adding `Math.min(left[i], right[i]) - height[i]` to the total trapped water.
6. Return the accumulated water volume.

**Why It Works:**
Water cannot overflow the lower of the two boundaries enclosing an index. Therefore, the water level above bar `i` is strictly bounded by `min(max_left, max_right)`. Since `height[i]` occupies space up to its own height, the net trapped water at bar `i` is `min(left[i], right[i]) - height[i]`. Summing this over all indices gives the total trapped water.

### Time Complexity

O(n)

### Space Complexity

O(n)

### AI-Generated Java Alternative

```java
class Solution {
    public int trap(int[] height) {
        if (height == null || height.length < 3) {
            return 0;
        }
        
        int n = height.length;
        int[] left = new int[n];
        int[] right = new int[n];
        
        left[0] = height[0];
        for (int i = 1; i < n; i++) {
            left[i] = Math.max(left[i - 1], height[i]);
        }
        
        right[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            right[i] = Math.max(right[i + 1], height[i]);
        }
        
        int totalWater = 0;
        for (int i = 0; i < n; i++) {
            totalWater += Math.min(left[i], right[i]) - height[i];
        }
        
        return totalWater;
    }
}
```

```python
class Solution:
    def trap(self, height: list[int]) -> int:
        n = len(height)
        if n < 3:
            return 0
            
        left = [0] * n
        right = [0] * n
        
        left[0] = height[0]
        for i in range(1, n):
            left[i] = max(left[i - 1], height[i])
            
        right[n - 1] = height[n - 1]
        for i in range(n - 2, -1, -1):
            right[i] = max(right[i + 1], height[i])
            
        total_water = 0
        for i in range(n):
            total_water += min(left[i], right[i]) - height[i]
            
        return total_water
```

```rust
impl Solution {
    pub fn trap(height: Vec<i32>) -> i32 {
        let n = height.len();
        if n < 3 {
            return 0;
        }
        
        let mut left = vec![0; n];
        let mut right = vec![0; n];
        
        left[0] = height[0];
        for i in 1..n {
            left[i] = left[i - 1].max(height[i]);
        }
        
        right[n - 1] = height[n - 1];
        for i in (0..n - 1).rev() {
            right[i] = right[i + 1].max(height[i]);
        }
        
        let mut total_water = 0;
        for i in 0..n {
            total_water += left[i].min(right[i]) - height[i];
        }
        
        total_water
    }
}
```
