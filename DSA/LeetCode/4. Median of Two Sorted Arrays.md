# 4. Median of Two Sorted Arrays

## 1. Problem Details

**Platform:** LeetCode

**Question Link:**
https://leetcode.com/problems/median-of-two-sorted-arrays/

**Question Name:** 4. Median of Two Sorted Arrays

**Question Description:**

Given two sorted arrays nums1 and nums2 of size m and n respectively, return the median of the two sorted arrays.



The overall run time complexity should be O(log (m+n)).



 


Example 1:



Input: nums1 = [1,3], nums2 = [2]
Output: 2.00000
Explanation: merged array = [1,2,3] and median is 2.


Example 2:



Input: nums1 = [1,2], nums2 = [3,4]
Output: 2.50000
Explanation: merged array = [1,2,3,4] and median is (2 + 3) / 2 = 2.5.


 


Constraints:




	• nums1.length == m
	• nums2.length == n
	• 0 <= m <= 1000
	• 0 <= n <= 1000
	• 1 <= m + n <= 2000
	• -106 <= nums1[i], nums2[i] <= 106

## 3. AI-Generated Approach

### Approach: Linear Two-Pointer Merge

Merge the two sorted input arrays into a single sorted array of size m + n using a two-pointer merge technique, then directly calculate the median using array indexing.

**Step-by-Step Reasoning:**
1. Allocate a new array `merged` of size m + n.
2. Use two pointers, `i` for `nums1` and `j` for `nums2`, iterating through both arrays to place the smaller element into `merged`.
3. Append any remaining elements from `nums1` or `nums2` into `merged`.
4. Check the total length `m + n`. If even, return the average of elements at index `(m + n) / 2 - 1` and `(m + n) / 2`. If odd, return the element at index `(m + n) / 2`.

**Why It Works:**
Because both arrays are already individually sorted, standard merge procedure from Merge Sort combines them into a single sorted sequence in linear time. Once sorted, the median element(s) reside at the exact middle index/indices.

### Time Complexity

O(m + n)

### Space Complexity

O(m + n)

### AI-Generated Java Alternative

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int m = nums1.length;
        int n = nums2.length;
        int length = m + n;
        int[] merged = new int[length];
        
        int i = 0, j = 0, k = 0;
        while (i < m && j < n) {
            if (nums1[i] <= nums2[j]) {
                merged[k++] = nums1[i++];
            } else {
                merged[k++] = nums2[j++];
            }
        }
        while (i < m) {
            merged[k++] = nums1[i++];
        }
        while (j < n) {
            merged[k++] = nums2[j++];
        }
        
        if (length % 2 == 0) {
            int mid1 = length / 2 - 1;
            int mid2 = length / 2;
            return (merged[mid1] + merged[mid2]) / 2.0;
        } else {
            int mid = length / 2;
            return (double) merged[mid];
        }
    }
}
```

```python
class Solution:
    def findMedianSortedArrays(self, nums1: list[int], nums2: list[int]) -> float:
        m, n = len(nums1), len(nums2)
        merged = []
        i, j = 0, 0
        
        while i < m and j < n:
            if nums1[i] <= nums2[j]:
                merged.append(nums1[i])
                i += 1
            else:
                merged.append(nums2[j])
                j += 1
                
        while i < m:
            merged.append(nums1[i])
            i += 1
        while j < n:
            merged.append(nums2[j])
            j += 1
            
        total_length = m + n
        if total_length % 2 == 0:
            mid1 = total_length // 2 - 1
            mid2 = total_length // 2
            return (merged[mid1] + merged[mid2]) / 2.0
        else:
            mid = total_length // 2
            return float(merged[mid])
```
