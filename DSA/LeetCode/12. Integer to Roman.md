# 12. Integer to Roman

## 1. Problem Details

**Platform:** LeetCode

**Question Link:**
https://leetcode.com/problems/integer-to-roman/

**Question Name:** 12. Integer to Roman

**Question Description:**

Seven different symbols represent Roman numerals with the following values:



SymbolValueI1V5X10L50C100D500M1000

Roman numerals are formed by appending the conversions of decimal place values from highest to lowest. Converting a decimal place value into a Roman numeral has the following rules:




	• If the value does not start with 4 or 9, select the symbol of the maximal value that can be subtracted from the input, append that symbol to the result, subtract its value, and convert the remainder to a Roman numeral.
	• If the value starts with 4 or 9 use the subtractive form representing one symbol subtracted from the following symbol, for example, 4 is 1 (I) less than 5 (V): IV and 9 is 1 (I) less than 10 (X): IX. Only the following subtractive forms are used: 4 (IV), 9 (IX), 40 (XL), 90 (XC), 400 (CD) and 900 (CM).
	• Only powers of 10 (I, X, C, M) can be appended consecutively at most 3 times to represent multiples of 10. You cannot append 5 (V), 50 (L), or 500 (D) multiple times. If you need to append a symbol 4 times use the subtractive form.


Given an integer, convert it to a Roman numeral.



 


Example 1:




Input: num = 3749



Output: "MMMDCCXLIX"



Explanation:



3000 = MMM as 1000 (M) + 1000 (M) + 1000 (M)
 700 = DCC as 500 (D) + 100 (C) + 100 (C)
  40 = XL as 10 (X) less of 50 (L)
   9 = IX as 1 (I) less of 10 (X)
Note: 49 is not 1 (I) less of 50 (L) because the conversion is based on decimal places



Example 2:




Input: num = 58



Output: "LVIII"



Explanation:



50 = L
 8 = VIII



Example 3:




Input: num = 1994



Output: "MCMXCIV"



Explanation:



1000 = M
 900 = CM
  90 = XC
   4 = IV



 


Constraints:




	• 1 <= num <= 3999

## 3. AI-Generated Approach

### Approach: Greedy Approach with Value-Symbol Mappings

We maintain two parallel arrays of Roman numeral values and their corresponding symbols, arranged in descending order from largest to smallest (including subtractive combinations like 900, 400, 90, 40, 9, 4). By greedily subtracting the largest possible value from the input number and appending its corresponding Roman symbol, we construct the resulting numeral correctly from left to right.

**Step-by-Step Reasoning:**
1. Define an array of integer values representing standard Roman symbols and their subtractive forms in descending order: [1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1].
2. Define a parallel array of string symbols corresponding to those values: ['M', 'CM', 'D', 'CD', 'C', 'XC', 'L', 'XL', 'X', 'IX', 'V', 'IV', 'I'].
3. Iterate through each value, and while the remaining number is greater than or equal to the current value, append the symbol to the result string and subtract the value from num.
4. Return the accumulated string once num becomes zero.

**Why It Works:**
The greedy choice property holds because Roman numerals are designed to be read from left to right by adding the largest possible values first. By systematically subtracting the maximal possible value at each step (including the standard subtractive pairs like IV, IX, etc.), we guarantee the shortest and most correct standard representation of the integer.

class Solution {
    public String intToRoman(int num) {
        int[] code = {1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1};
        String[] s = {"M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"};

        for (int i = 0; i < code.length; i++) {
            while (num >= code[i]) {
                sb.append(s[i]);
                num -= code[i];
            }
        }
        return sb.toString();
    }
}

    def intToRoman(self, num: int) -> str:
        code = [1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1]
        s = ["M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"]
        res = []
        for i in range(len(code)):
            while num >= code[i]:
