# 35. Search Insert Position

## 1. Problem Details

**Platform:** LeetCode

**Question Link:**
https://leetcode.com/problems/search-insert-position/

**Question Name:** 35. Search Insert Position

**Question Description:**

Given a sorted array of distinct integers and a target value, return the index if the target is found. If not, return the index where it would be if it were inserted in order.

You must write an algorithm with O(log n) runtime complexity.

Example 1:

Input: nums = [1,3,5,6], target = 5
Output: 2

Example 2:

Input: nums = [1,3,5,6], target = 2
Output: 1

Example 3:

Input: nums = [1,3,5,6], target = 7
Output: 4

Constraints:

• 1 <= nums.length <= 104

• -104 <= nums[i] <= 104

• nums contains distinct values sorted in ascending order.

• -104 <= target <= 104

## 3. AI-Generated Approach

### Approach: Binary Search

Perform a binary search over the sorted array. If the target is present, return its index. If target is absent, the search loop will terminate with `left` pointing precisely to the position where the target should be inserted.

**Step-by-Step Reasoning:**
1. Initialize `left` pointer to 0 and `right` pointer to `nums.length - 1`.
2. Calculate `mid = left + (right - left) / 2` inside a loop while `left <= right`.
3. If `nums[mid] == target`, return `mid`.
4. If `nums[mid] < target`, adjust search range to right half by setting `left = mid + 1`.
5. If `nums[mid] > target`, adjust search range to left half by setting `right = mid - 1`.
6. If loop terminates without finding `target`, return `left` as the insertion index.

**Why It Works:**
Binary search iteratively eliminates half of the search space based on sorted order. When the target does not exist, the binary search terminates when `left > right`. At termination, `left` will index the smallest element that is greater than `target` (or `nums.length` if all elements are smaller), which is the exact lower bound index where `target` should be inserted.

### Time Complexity

O(log n)

### Space Complexity

O(1)

impl Solution {
    pub fn search_insert(nums: Vec<i32>, target: i32) -> i32 {
        let mut left: i32 = 0;
        let mut right: i32 = nums.len() as i32 - 1;

        while left <= right {
            let mid = left + (right - left) / 2;
            let mid_idx = mid as usize;
            
            if nums[mid_idx] == target {
                return mid;
            } else if nums[mid_idx] < target {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        left
    }
}
