# 3411. Maximum Subarray With Equal Products

## 1. Problem Details

**Platform:** LeetCode

**Question Name:** 3411. Maximum Subarray With Equal Products

**Question Description:**

You are given an array of positive integers nums.

An array arr is called product equivalent if prod(arr) == lcm(arr) * gcd(arr), where:

• prod(arr) is the product of all elements of arr.

• gcd(arr) is the GCD of all elements of arr.

• lcm(arr) is the LCM of all elements of arr.

Return the length of the longest product equivalent subarray of nums.

OriginalJavaExample 1:

Input: nums = [1,2,1,2,1,1,1]

Output: 5

Explanation:

The longest product equivalent subarray is [1, 2, 1, 1, 1], where prod([1, 2, 1, 1, 1]) = 2, gcd([1, 2, 1, 1, 1]) = 1, and lcm([1, 2, 1, 1, 1]) = 2.

Example 2:

Input: nums = [2,3,4,5,6]

Output: 3

Explanation:

The longest product equivalent subarray is [3, 4, 5].

Example 3:

Input: nums = [1,2,3,1,4,5,1]

Output: 5

Constraints:

• 2 <= nums.length <= 100

• 1 <= nums[i] <= 10

## 3. AI-Generated Approach

### Approach: Brute Force with Running Product, GCD, and LCM

Given the constraints where `nums.length <= 100` and `nums[i] <= 10`, we can iterate over all possible subarrays using a nested loop, dynamically computing the product, greatest common divisor (GCD), and least common multiple (LCM). For each subarray, check if the condition `product == lcm * gcd` holds, and track the maximum length found.

**Step-by-Step Reasoning:**
1. Initialize `ans = 0` to store the maximum length of a product-equivalent subarray.
2. Iterate `left` from 0 to `n - 1` to define the start of each subarray.
3. For each `left`, initialize `product = 1`, `currlcm = 1`, and `currgcd = 0`.
4. Iterate `right` from `left` to `n - 1`, updating `product`, `currgcd` using the Euclidean algorithm, and `currlcm`.
5. Break early or cap values to prevent overflow if they exceed reasonable bounds, checking if `product == currlcm * currgcd` at each step to update `ans`.

**Why It Works:**
Since the array length is at most 100 and values are at most 10, the total number of subarrays is $O(n^2) = 10000$, which easily runs within the time limit. The product grows fast, but with numbers $\le 10$, we can safely compute values or guard against overflow using `long`.

```java
import java.util.*;

public class Solution {
    public static int maxLength(int[] nums) {
        int n = nums.length;
        int ans = 0;

        for (int left = 0; left < n; left++) {
            long product = 1;
            long currlcm = 1;
            int currgcd = 0;

            for (int right = left; right < n; right++) {
                int num = nums[right];
                product *= num;
                currgcd = (currgcd == 0) ? num : gcd(currgcd, num);
                currlcm = (currlcm * num) / gcd((int)currlcm, num);

                if (product > 1e18) break; // prevent overflow

                if (product == currlcm * currgcd) {
                    ans = Math.max(ans, right - left + 1);
                }
            }
        }
        return ans;
    }

    private static int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

```rust
    pub fn max_length(nums: Vec<i32>) -> i32 {
        fn gcd(mut a: u64, mut b: u64) -> u64 {
            while b != 0 {
                let temp = b;
                b = a % b;
                a = temp;
            }
            a
        }

        let n = nums.len();
        let mut ans = 0;

        for left in 0..n {
            let mut product: u64 = 1;
            let mut currlcm: u64 = 1;
            let mut currgcd: u64 = 0;

            for right in left..n {
                let num = nums[right] as u64;
                product = product.saturating_mul(num);
                currgcd = if currgcd == 0 { num } else { gcd(currgcd, num) };
                
                let g = gcd(currlcm, num);
                currlcm = (currlcm / g) * num;

                if product == currlcm * currgcd {
                    ans = std::cmp::max(ans, (right - left + 1) as i32);
                }
            }
        }
        ans
    }
```
