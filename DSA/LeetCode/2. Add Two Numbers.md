# 2. Add Two Numbers

## 1. Problem Details

**Platform:** LeetCode

**Question Link:**
https://leetcode.com/problems/add-two-numbers

**Question Name:** 2. Add Two Numbers

**Question Description:**

You are given two non-empty linked lists representing two non-negative integers. The digits are stored in reverse order, and each of their nodes contains a single digit. Add the two numbers and return the sum as a linked list.



You may assume the two numbers do not contain any leading zero, except the number 0 itself.



 


Example 1:



Input: l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
Explanation: 342 + 465 = 807.


Example 2:



Input: l1 = [0], l2 = [0]
Output: [0]


Example 3:



Input: l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
Output: [8,9,9,9,0,0,0,1]


 


Constraints:




	• The number of nodes in each linked list is in the range [1, 100].
	• 0 <= Node.val <= 9
	• It is guaranteed that the list represents a number that does not have leading zeros.

## 3. AI-Generated Approach

### Approach: Elementary Math Addition with Carry

Traverse both linked lists simultaneously from head to tail (least significant digit to most significant digit), adding corresponding digits along with any carry from the previous position, and construct a new linked list for the result.

**Step-by-Step Reasoning:**
1. Initialize a dummy head node to simplify list construction and maintain a pointer 'curr' pointing to it.
2. Initialize an integer variable 'carry' to 0.
3. Iterate while either list node (l1 or l2) is not null, or 'carry' is non-zero.
4. At each step, calculate sum = carry + (l1 != null ? l1.val : 0) + (l2 != null ? l2.val : 0).
5. Update carry = sum / 10 and create a new node with value sum % 10 attached to curr.next.
6. Advance l1 (if not null), l2 (if not null), and curr to curr.next.
7. Return dummy.next as the head of the resulting linked list.

**Why It Works:**
Because the digits are stored in reverse order, the head of each list represents the least significant digit (units place). This perfectly aligns with standard columnar addition where addition proceeds from lowest place value to highest place value with carry propagation.

### Time Complexity

O(max(N, M))

### Space Complexity

O(1)

### AI-Generated Java Alternative

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummyHead = new ListNode(0);
        ListNode curr = dummyHead;
        int carry = 0;

        while (l1 != null || l2 != null || carry != 0) {
            int val1 = (l1 != null) ? l1.val : 0;
            int val2 = (l2 != null) ? l2.val : 0;
            int sum = val1 + val2 + carry;

            carry = sum / 10;
            curr.next = new ListNode(sum % 10);
            curr = curr.next;

            if (l1 != null) {
                l1 = l1.next;
            }
            if (l2 != null) {
                l2 = l2.next;
            }
        }

        return dummyHead.next;
    }
}
```

```python
from typing import Optional

class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy_head = ListNode(0)
        curr = dummy_head
        carry = 0

        while l1 or l2 or carry:
            val1 = l1.val if l1 else 0
            val2 = l2.val if l2 else 0
            total = val1 + val2 + carry

            carry, digit = divmod(total, 10)
            curr.next = ListNode(digit)
            curr = curr.next

            if l1:
                l1 = l1.next
            if l2:
                l2 = l2.next

        return dummy_head.next
```

## 7. Rust Solution

### AI-Generated Rust Implementation

```rust
// Definition for singly-linked list.
// #[derive(PartialEq, Eq, Clone, Debug)]
// pub struct ListNode {
//   pub val: i32,
//   pub next: Option<Box<ListNode>>
// }
// 
// impl ListNode {
//   #[inline]
//   fn new(val: i32) -> Self {
//     ListNode {
//       next: None,
//       val
//     }
//   }
// }
impl Solution {
    pub fn add_two_numbers(
        mut l1: Option<Box<ListNode>>,
        mut l2: Option<Box<ListNode>>,
    ) -> Option<Box<ListNode>> {
        let mut dummy_head = Some(Box::new(ListNode::new(0)));
        let mut curr = dummy_head.as_mut();
        let mut carry = 0;

        while l1.is_some() || l2.is_some() || carry != 0 {
            let mut sum = carry;

            if let Some(node) = l1 {
                sum += node.val;
                l1 = node.next;
            }
            if let Some(node) = l2 {
                sum += node.val;
                l2 = node.next;
            }

            carry = sum / 10;
            let next_node = Some(Box::new(ListNode::new(sum % 10)));

            if let Some(ref mut c) = curr {
                c.next = next_node;
                curr = c.next.as_mut();
            }
        }

        dummy_head.unwrap().next
    }
}
```
