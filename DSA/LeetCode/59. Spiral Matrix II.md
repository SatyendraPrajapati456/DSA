# 59. Spiral Matrix II

## 1. Problem Details

**Platform:** LeetCode

**Question Link:**
https://leetcode.com/problems/spiral-matrix-ii/description/

**Question Name:** 59. Spiral Matrix II

**Question Description:**

Given a positive integer n, generate an n x n matrix filled with elements from 1 to n2 in spiral order.

Example 1:

Input: n = 3
Output: [[1,2,3],[8,9,4],[7,6,5]]

Example 2:

Input: n = 1
Output: [[1]]

Constraints:

• 1 <= n <= 20

## 3. AI-Generated Approach

### Approach: Matrix Simulation with Boundary Pointers

Simulate the spiral filling process layer by layer using four boundary pointers (top, bottom, left, right). Incrementally fill numbers from 1 to n^2 while shrinking the boundaries.

**Step-by-Step Reasoning:**
1. Initialize an n x n matrix and four pointers: top=0, bottom=n-1, left=0, right=n-1, and a counter starting at 1.
2. While top <= bottom and left <= right, traverse the top row from left to right, then increment top.
3. Traverse the right column from top to bottom, then decrement right.
4. Traverse the bottom row from right to left (if top <= bottom), then decrement bottom.
5. Traverse the left column from bottom to top (if left <= right), then increment left.

**Why It Works:**
By maintaining strict boundaries for the current layer and shrinking them inward after each direction traversal, we guarantee every cell is visited exactly once in the correct spiral sequence without overlapping.

### Time Complexity

O(n^2)

### Space Complexity

O(1)

class Solution {
    public int[][] generateMatrix(int n) {
        int[][] matrix = new int[n][n];
        int top = 0, bottom = n - 1;
        int left = 0, right = n - 1;
        int count = 1;
        
        while (top <= bottom && left <= right) {
            for (int i = left; i <= right; i++) {
                matrix[top][i] = count++;
            }
            top++;
            
            for (int i = top; i <= bottom; i++) {
                matrix[i][right] = count++;
            }
            right--;
            
            if (top <= bottom) {
                for (int i = right; i >= left; i--) {
                    matrix[bottom][i] = count++;
                }
                bottom--;
            }
            
            if (left <= right) {
                for (int i = bottom; i >= top; i--) {
                    matrix[i][left] = count++;
                }
                left++;
            }
        }
        return matrix;
    }
}

class Solution:
    def generateMatrix(self, n: int) -> list[list[int]]:
        matrix = [[0] * n for _ in range(n)]
        top, bottom = 0, n - 1
        left, right = 0, n - 1
        count = 1
        
        while top <= bottom and left <= right:
            for i in range(left, right + 1):
                matrix[top][i] = count
                count += 1
            top += 1
            
            for i in range(top, bottom + 1):
                matrix[i][right] = count
                count += 1
            right -= 1
            
            if top <= bottom:
                for i in range(right, left - 1, -1):
                    matrix[bottom][i] = count
                    count += 1
                bottom -= 1
            
            if left <= right:
                for i in range(bottom, top - 1, -1):
                    matrix[i][left] = count
                    count += 1
                left += 1
                
        return matrix
