# 175. Combine Two Tables

## 1. Problem Details

**Platform:** LeetCode

**Question Link:**
https://leetcode.com/problems/combine-two-tables

**Question Name:** 175. Combine Two Tables

**Question Description:**

Table: Person



+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| personId    | int     |
| lastName    | varchar |
| firstName   | varchar |
+-------------+---------+
personId is the primary key (column with unique values) for this table.
This table contains information about the ID of some persons and their first and last names.


 



Table: Address



+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| addressId   | int     |
| personId    | int     |
| city        | varchar |
| state       | varchar |
+-------------+---------+
addressId is the primary key (column with unique values) for this table.
Each row of this table contains information about the city and state of one person with ID = PersonId.


 



Write a solution to report the first name, last name, city, and state of each person in the Person table. If the address of a personId is not present in the Address table, report null instead.



Return the result table in any order.



The result format is in the following example.



 


Example 1:



Input: 
Person table:
+----------+----------+-----------+
| personId | lastName | firstName |
+----------+----------+-----------+
| 1        | Wang     | Allen     |
| 2        | Alice    | Bob       |
+----------+----------+-----------+
Address table:
+-----------+----------+---------------+------------+
| addressId | personId | city          | state      |
+-----------+----------+---------------+------------+
| 1         | 2        | New York City | New York   |
| 2         | 3        | Leetcode      | California |
+-----------+----------+---------------+------------+
Output: 
+-----------+----------+---------------+----------+
| firstName | lastName | city          | state    |
+-----------+----------+---------------+----------+
| Allen     | Wang     | Null          | Null     |
| Bob       | Alice    | New York City | New York |
+-----------+----------+---------------+----------+
Explanation: 
There is no address in the address table for the personId = 1 so we return null in their city and state.
addressId = 1 contains information about the address of personId = 2.

## 3. AI-Generated Approach

### Approach: Hash Join (Left Outer Join)

Simulate a relational LEFT JOIN operation using a hash map. Build an index on the Address table keyed by personId, then iterate through the Person table, retrieving corresponding address attributes or null if absent.

**Step-by-Step Reasoning:**
1. Scan the Address table and populate a hash map where the key is personId and the value is the tuple (city, state).
2. Iterate over each row in the Person table.
3. For each person, look up their personId in the Address hash map.
4. If found, combine firstName, lastName, city, and state; otherwise, output firstName, lastName with null/None for city and state.
5. Append each combined record to the result collection.

**Why It Works:**
In relational algebra, a Left Outer Join preserves all rows from the left relation (Person) regardless of whether a matching record exists in the right relation (Address). A hash join accomplishes this in linear time by enabling O(1) average-time lookups for each primary record.

### Time Complexity

O(N + M) where N is the number of records in Person and M is the number of records in Address.

### Space Complexity

O(M) to store the address lookup map, plus O(N) for the resulting output.

```java
import java.util.*;

public class Solution {
    public static class Person {
        public int personId;
        public String lastName;
        public String firstName;

        public Person(int personId, String lastName, String firstName) {
            this.personId = personId;
            this.lastName = lastName;
            this.firstName = firstName;
        }
    }

    public static class Address {
        public int addressId;
        public int personId;
        public String city;
        public String state;

        public Address(int addressId, int personId, String city, String state) {
            this.addressId = addressId;
            this.personId = personId;
            this.city = city;
            this.state = state;
        }
    }

    public static class ResultRow {
        public String firstName;
        public String lastName;
        public String city;
        public String state;

        public ResultRow(String firstName, String lastName, String city, String state) {
            this.firstName = firstName;
            this.lastName = lastName;
            this.city = city;
            this.state = state;
        }
    }

    public List<ResultRow> combineTwoTables(List<Person> persons, List<Address> addresses) {
        Map<Integer, Address> addressMap = new HashMap<>();
        for (Address addr : addresses) {
            addressMap.put(addr.personId, addr);
        }

        List<ResultRow> result = new ArrayList<>(persons.size());
        for (Person p : persons) {
            Address addr = addressMap.get(p.personId);
            String city = (addr != null) ? addr.city : null;
            String state = (addr != null) ? addr.state : null;
            result.add(new ResultRow(p.firstName, p.lastName, city, state));
        }

        return result;
    }
}
```

```python
from typing import List, Dict, Optional, Tuple, Any

class Solution:
    def combineTwoTables(
        self, 
        persons: List[Dict[str, Any]], 
        addresses: List[Dict[str, Any]]
    ) -> List[Dict[str, Optional[str]]]:
        # Map personId to (city, state)
        address_map = {
            addr["personId"]: (addr["city"], addr["state"])
            for addr in addresses
        }

        result = []
        for person in persons:
            addr = address_map.get(person["personId"])
            city, state = addr if addr else (None, None)
            result.append({
                "firstName": person["firstName"],
                "lastName": person["lastName"],
                "city": city,
                "state": state
            })

        return result
```

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <unordered_map>
#include <optional>

struct Person {
    int personId;
    std::string lastName;
    std::string firstName;
};

struct Address {
    int addressId;
    int personId;
    std::string city;
    std::string state;
};

struct ResultRow {
    std::string firstName;
    std::string lastName;
    std::optional<std::string> city;
    std::optional<std::string> state;
};

class Solution {
public:
    std::vector<ResultRow> combineTwoTables(const std::vector<Person>& persons, const std::vector<Address>& addresses) {
        std::unordered_map<int, std::pair<std::string, std::string>> addressMap;
        for (const auto& addr : addresses) {
            addressMap[addr.personId] = {addr.city, addr.state};
        }

        std::vector<ResultRow> result;
        result.reserve(persons.size());

        for (const auto& person : persons) {
            auto it = addressMap.find(person.personId);
            if (it != addressMap.end()) {
                result.push_back({person.firstName, person.lastName, it->second.first, it->second.second});
            } else {
                result.push_back({person.firstName, person.lastName, std::nullopt, std::nullopt});
            }
        }

        return result;
    }
};
```

```rust
use std::collections::HashMap;

#[derive(Debug, Clone)]
pub struct Person {
    pub person_id: i32,
    pub last_name: String,
    pub first_name: String,
}

#[derive(Debug, Clone)]
pub struct Address {
    pub address_id: i32,
    pub person_id: i32,
    pub city: String,
    pub state: String,
}

#[derive(Debug, PartialEq, Eq)]
pub struct ResultRow {
    pub first_name: String,
    pub last_name: String,
    pub city: Option<String>,
    pub state: Option<String>,
}

pub struct Solution;

impl Solution {
    pub fn combine_two_tables(persons: &[Person], addresses: &[Address]) -> Vec<ResultRow> {
        let address_map: HashMap<i32, (&str, &str)> = addresses
            .iter()
            .map(|a| (a.person_id, (a.city.as_str(), a.state.as_str())))
            .collect();

        persons
            .iter()
            .map(|p| {
                let (city, state) = match address_map.get(&p.person_id) {
                    Some(&(c, s)) => (Some(c.to_string()), Some(s.to_string())),
                    None => (None, None),
                };
                ResultRow {
                    first_name: p.first_name.clone(),
                    last_name: p.last_name.clone(),
                    city,
                    state,
                }
            })
            .collect()
    }
}
```
