# 3360. Stone Removal Game

## 1. Problem Details

**Platform:** LeetCode

**Question Link:**
https://leetcode.com/problems/stone-removal-game/

**Question Name:** 3360. Stone Removal Game

**Question Description:**

Alice and Bob are playing a game where they take turns removing stones from a pile, with Alice going first.

• Alice starts by removing exactly 10 stones on her first turn.

• For each subsequent turn, each player removes exactly 1 fewer stone than the previous opponent.

The player who cannot make a move loses the game.

Given a positive integer n, return true if Alice wins the game and false otherwise.

OriginalJavaExample 1:

Input: n = 12

Output: true

Explanation:

• Alice removes 10 stones on her first turn, leaving 2 stones for Bob.

• Bob cannot remove 9 stones, so Alice wins.

Example 2:

Input: n = 1

Output: false

Explanation:

• Alice cannot remove 10 stones, so Alice loses.

Constraints:

• 1 <= n <= 50

## 3. AI-Generated Approach

### Approach: Simulation

Simulate the stone removal game turn by turn starting from 10 stones, decrementing the stone count per turn until a player cannot make a valid move.

**Step-by-Step Reasoning:**
1. Initialize a boolean flag to track turn parity and a variable 'baba' starting at 10 to represent the number of stones to remove.
2. Iterate while the total number of stones 'n' is greater than 0.
3. Subtract 'baba' stones from 'n', decrement 'baba' by 1, and toggle the turn flag.
4. Return the final boolean flag indicating whether Alice made the last successful move.

**Why It Works:**
Since the constraints are extremely small (n <= 50), directly simulating each turn perfectly reflects the game mechanics. Alice loses if she cannot make her first move (n < 10), and the alternating turns correctly determine who runs out of stones first.

### Original Accepted Submission

```java
class Solution {
    public boolean canAliceWin(int n) {
        boolean flag=true;
        int baba=10;
        while(n>0)
        {
            n=n-baba;
            baba--;
            flag=!flag;
        }  
        return flag;
    }
}
```
