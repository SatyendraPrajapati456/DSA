# 3360. Stone Removal Game

## 1. Problem Details

**Platform:** LeetCode

**Question Link:**
https://leetcode.com/problems/stone-removal-game/

**Question Name:** 3360. Stone Removal Game

**Question Description:**

Alice and Bob are playing a game where they take turns removing stones from a pile, with Alice going first.

• Alice starts by removing exactly 10 stones on her first turn.

• For each subsequent turn, each player removes exactly 1 fewer stone than the previous opponent.

The player who cannot make a move loses the game.

Given a positive integer n, return true if Alice wins the game and false otherwise.

OriginalJavaExample 1:

Input: n = 12

Output: true

Explanation:

• Alice removes 10 stones on her first turn, leaving 2 stones for Bob.

• Bob cannot remove 9 stones, so Alice wins.

Example 2:

Input: n = 1

Output: false

Explanation:

• Alice cannot remove 10 stones, so Alice loses.

Constraints:

• 1 <= n <= 50

## 3. AI-Generated Approach

### Approach: Simulation

Simulate the turn-based stone removal game step by step until no more stones can be removed or a player cannot make a valid move.

**Step-by-Step Reasoning:**
1. Initialize a boolean flag to track whose turn it is (true for Alice, false for Bob) and a variable for the number of stones to remove starting at 10.
2. Iterate while the total stones n is greater than 0.
3. In each iteration, check if n is less than the current stones required to remove; if so, the current player cannot move and loses, returning the inverted flag.
4. Subtract the required stones from n, decrement the required stones for the next turn, and toggle the turn flag.

**Why It Works:**
Since the constraints are very small (n <= 50), directly simulating the exact rules of the game guarantees correctness without requiring complex mathematical formulas.

### Time Complexity

O(sqrt(n))

### Space Complexity

O(1)

### Original Accepted Submission

```java
class Solution {
    public boolean canAliceWin(int n) {
        boolean flag=true;
        int baba=10;
        while(n>0)
        {
            if(n==baba)
            {
                return flag;
            }
            n=n-baba;
            baba--;
            flag=!flag;
        }  
        return flag;
    }
}
```
